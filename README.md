# Pokemon Wonders

Browser-based creature battle game with a Node.js server.

## Run locally

Install Node.js, open a terminal in this folder, and run:

```powershell
node backend/server.js
```

Open http://localhost:3000 in your browser.

## Project files

- `backend/` contains the server, battle engine, and game data.
- `frontend/` contains the game page, styles, and browser code.
