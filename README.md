# Pokemon Wonders

Browser-based creature battle game with a Node.js server.

## Run locally

Install Node.js, open a terminal in this folder, and run:

```powershell
node server.js
```

Open http://localhost:3000 in your browser.

## Project files

- `frontend/` contains the game page, styles, and browser code.
- `server.js` serves the frontend and game API.
- `engine.js` and `data.js` contain the battle logic and game data.
